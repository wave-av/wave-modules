# wave-modules

Modular streaming components with YAML manifests for WAVE edge devices.

## Modules

| Module | Category | Description |
|--------|----------|-------------|
| wave-srt-in | Video input | SRT stream receive + decode |
| wave-hdmi-out | Video output | HDMI display via DRM/KMS |
| wave-ndi-in | Video input | NDI 5 receive with auto-discover |
| wave-companion | Control | Bitfocus Companion integration |
| wave-prometheus | Monitoring | Custom WAVE metrics + node_exporter |

See [MODULE-CATALOG.md](MODULE-CATALOG.md) for all 50+ available modules.
